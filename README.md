## 🔥 What is NexLead?

NexLead is an AI-powered lead generation and business email discovery platform built to find verified business emails at scale.

Unlike traditional email finders that rely on limited databases, NexLead aggressively scans the public internet using:

- 🌐 Multiple search engines
- 📁 Business directories
- 🕸 Deep website crawling
- 📱 Social media platforms
- 🔍 Contact page analysis
- 🧠 Smart email extraction logic

The goal is simple:

> Find emails other tools miss.

# 🚀 Installation

## 1. Clone Repository

```bash
git clone https://github.com/yourusername/nexlead.git
cd nexlead
```

---

## 2. Install Dependencies

```bash
pip install flask flask-cors pandas requests beautifulsoup4 lxml openpyxl
```

---

## 3. Run Project

```bash
python app.py
```

or

```bash
python email_hunter.py
```

---

## 4. Open in Browser

```bash
http://localhost:5000
```
